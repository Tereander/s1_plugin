# Инструкция по установке и использованию плагина "SimpleOne Color Plugin"

Этот плагин значительно улучшает работу с SimpleOne, добавляя следующие функции:

## Новые возможности (версия 1.8.1):

### 1. **Панель активности заявок**
*   **Новая кнопка "Активность":** В каждой строке таблицы появилась кнопка "Активность"
*   **Просмотр без перехода:** При клике открывается нижняя панель, не покидая текущую страницу
*   **Два раздела панели:**
    *   **Левый раздел:** Все данные из строки таблицы
    *   **Правый раздел:** Полная лента активности заявки с оригинальным оформлением

### 2. **Улучшенная стилизация статусов**
*   **Выделение цветом:** Статусы заявок ("В работе", "Закрыта", "Выполнено" и др.) выделяются бирюзовым цветом
*   **Автоматическое обновление:** Стили применяются сразу при загрузке страницы и при любых изменениях

### 3. **Подсветка SLA сроков**
*   **Автоматическая проверка:** Плагин отслеживает поля с датами окончания
*   **Важное уточнение:** Если в строке заполнено несколько полей с датами, используется **первое слева заполненное поле**
*   **Цветовая индикация:**
    *   **Жёлтый:** SLA истекает в течение 1 суток
    *   **Красный:** SLA просрочено

### 4. **Гибкая работа с таблицами**
*   **Изменение ширины столбцов:** Перетаскивайте границы между заголовками столбцов
*   **Автоподгонка текста:** При увеличении ширины столбца, обрезанный текст отображается полностью

### 5. **Автообновление страниц**
*   **Настраиваемый интервал:** От 1 секунды и выше
*   **Автоматическая работа:** Страницы списков обновляются по заданному расписанию

## Особенности определения сроков SLA

Плагин поддерживает следующие поля с датами окончания:
- `Плановая дата/время окончания`
- `Плановая дата/время окончания в BMC`
- `Согласованное время окончания`
- `Плановая дата/время окончания для ПБ`

**Правило определения даты:**
1. Плагин сканирует таблицу слева направо
2. Для подсветки строки используется **первое заполненное поле**, найденное в этом порядке
3. Если в строке заполнено несколько полей с разными датами, приоритет имеет **самое левое заполненное поле**
4. Если все поля пустые или содержат `(не задано)`/`none`, подсветка не применяется

**Пример:**  
Если в строке заполнены поля:
- Колонка 3: `Согласованное время окончания` = 15.12.2023 14:00
- Колонка 5: `Плановая дата/время окончания` = 16.12.2023 10:00

Для подсветки будет использоваться дата из **колонки 3** (15.12.2023 14:00), так как она находится левее.

## Установка плагина

### Для Google Chrome
1.  **Скачайте архив с плагином:** Получите папку со всеми файлами плагина
2.  **Распакуйте архив:** Извлеките файлы в отдельную папку на компьютере
3.  **Откройте Google Chrome**
4.  **Перейдите в меню расширений:**
    *   Введите в адресной строке: `chrome://extensions/`
    *   Или: **три точки** → **"Дополнительные инструменты"** → **"Расширения"**
5.  **Включите режим разработчика:** Переключите тумблер в правом верхнем углу
6.  **Загрузите распакованное расширение:**
    *   Нажмите **"Загрузить распакованное расширение"**
    *   Выберите папку с файлами плагина
7.  **Готово:** Плагин установлен и активен

### Для Mozilla FireFox
1.  **Скачайте архив с плагином:** Получите папку со всеми файлами плагина
2.  **Распакуйте архив:** Извлеките файлы в отдельную папку на компьютере
3.  **Извлеките .xpi файл из папки mozilla**
4.  **Откройте Mozilla FireFox**
5.  **Перейдите в меню расширений:**
    *   Введите в адресной строке: `about:addons`
    *   Или: **меню приложения** → **"Расширения и темы"**
6.  **Загрузите расширение:**
    *   Нажмите **Управление расширениями** → **"Установить дополнение из файла"**
    *   Выберите файл с плагином плагина
7.  **Готово:** Плагин установлен и активен

## Использование плагина

Плагин автоматически работает на всех страницах SimpleOne (`https://sd.jet.su/*`).

### На странице списка заявок:

1.  **Кнопка "Активность":**
    *   Находится рядом с номером заявки в каждой строке
    *   При клике открывается нижняя панель
    *   **Левая часть:** Данные заявки из текущей строки
    *   **Правая часть:** Полная история активности заявки

2.  **Подсветка сроков:**
    *   Строки автоматически окрашиваются в зависимости от SLA
    *   **Примечание:** Используется первое слева заполненное поле с датой
    *   Жёлтый — скоро истечёт (менее 24 часов)
    *   Красный — просрочено

3.  **Изменение ширины столбцов:**
    *   Наведите курсор на границу между заголовками
    *   Перетащите для изменения ширины
    *   Текст автоматически адаптируется

### На странице конкретной заявки:

1.  **Стилизованные статусы:**
    *   Статус заявки выделен бирюзовым цветом
    *   Чётко видно текущее состояние работы

2.  **Автообновление статуса:**
    *   Статус автоматически обновляется при изменениях
    *   Не нужно обновлять страницу вручную

### Настройки плагина:

1.  **Откройте настройки:** Нажмите на иконку плагина в правом верхнем углу Chrome
2.  **Доступные опции:**
    *   ✅ **Включить автообновление** — периодическое обновление страниц списков
    *   🔢 **Интервал обновления** — от 1 секунды и выше
3.  **Нажмите "Сохранить"**

## Особенности работы

### Производительность:
*   Плагин оптимизирован для быстрой работы
*   Не замедляет загрузку страниц
*   Автоматически адаптируется к изменениям на странице

### Безопасность:
*   Работает только на домене `sd.jet.su`
*   Не собирает и не передаёт данные пользователя
*   Использует только официальные API браузера

### Совместимость:
*   Работает с современными версиями SimpleOne
*   Поддерживает SPA-навигацию (одностраничные приложения)
*   Автоматически определяет тип страницы

## Устранение неполадок

### Если кнопка "Активность" не появляется:
1.  Убедитесь, что находитесь на странице списка
2.  Проверьте, включён ли плагин в `chrome://extensions/`
3.  Обновите страницу (F5)

### Если не работает подсветка SLA:
1.  Проверьте, заполнено ли хотя бы одно поле с датой в таблице
2.  Проверьте, что поле добавлено через фильтр в таблицу
3.  Убедитесь, что формат даты соответствует `дд.мм.гггг чч:мм`
4.  **Помните:** Используется первое слева заполненное поле

### Если не работает автообновление:
1.  Проверьте настройки плагина
2.  Убедитесь, что галочка "Включить автообновление" установлена
3.  Укажите интервал не менее 1 секунды

### Если плагин не устанавливается:
1.  Убедитесь, что включён "Режим разработчика"
2.  Проверьте, что все файлы плагина в одной папке
3.  Попробуйте перезапустить Chrome

## Обновление плагина

### Для распакованной версии:
1.  Замените файлы в папке плагина
2.  На странице `chrome://extensions/` нажмите 🔄 "Обновить"

---

**Примечание:** Плагин разработан для внутреннего использования в JetMS. Все функции тестируются на актуальной версии SimpleOne и регулярно обновляются.
